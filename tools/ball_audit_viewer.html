What the comparison establishes

The primary comparison processes both versions from frame zero and scores the labeled frames 150?329. The before run acquires the wrong appearance. A separate cold-start experiment begins at frame 150. Both versions use the same start within each experiment; neither result is whole-match accuracy. Fixes use the selected yellow-ball profile, remove the lob-clipping mask, and exclude uncertain contact transitions from flight fits. No speed uncertainty thresholds were loosened.
